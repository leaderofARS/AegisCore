# AegisCore Documentation

Welcome to the official documentation for **AegisCore**, a high-performance, multithreaded TCP game lobby server written in Java 21.

AegisCore manages player session establishment, room management, ready checks, and matchmaking queues—providing the essential lobby infrastructure layer required by multiplayer games before players enter a live game world instance.
